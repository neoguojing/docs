## llm as a judge 大模型评价
- 规模化大
- 一致性
- 成本低
- 可解释
- 位置偏见： 前面的分数高，可疑调转顺序
- 长度偏见： 预训练都是长文本； prompt纠正
- 自我偏好： 模型对自己的内容高分； 交叉评分
- 风格偏好： 工整回答分数高
- 知识边界： 不知道自己不知道； prompt
