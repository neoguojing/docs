现代视觉 Backbone（除原生 ViT 外）均采用层级化（Hierarchical）结构，通常划分为 4 到 5 个 Stage。每次进入新 Stage，特征图的空间分辨率通常减半（下采样 H/2,W/2），而通道数翻倍（C×2）。网络输出的不同尺度特征图（通常是原图分辨率的 1/4、1/8、1/16、1/32 大小）分别负责捕捉浅层的边缘纹理细节和深层的全局语义信息，这是后续目标检测（FPN）、图像分割等多尺度任务的绝对基石。

面试核心考点

为什么 Stage 1 (Stem) 要用 7x7 大卷积核并且连续降采样两次？
如果一开始就用 3x3 卷积且不降维，224x224 的高分辨率图会占用极其庞大的显存（激活值太大），并消耗海量计算力。7x7 卷积（Stride=2）配合 3x3 MaxPool（Stride=2）能迅速将分辨率压缩至 1/4，在保留足够底层像素信息的同时，极大地卸载了后续 Stage 的计算负担。

为什么 Stage 4 (C4) 的 Block 数量总是最多的？
在 1/16 的分辨率下，特征图既保留了足够的空间位置信息（不至于像 1/32 那样糊成一团），又具备了足够高级的语义特征。加深这一层，能为后续的 Dense Prediction（如目标检测、实例分割）提供性价比最高的特征表达。

在目标检测中，为什么不直接使用 C5 输出的特征？
C5 经过了 32 倍下采样，一个 32×32 像素的小目标在 C5 特征图上仅仅只有 1×1 个像素，甚至会在池化过程中直接丢失。因此必须将 C5 的强语义特征上采样，与 C2、C3、C4 结合（即 FPN 结构），才能同时检测大中小目标。

# 视觉骨干网络 (Backbone) 架构演进与核心设计（深度展开版）

从卷积神经网络 (CNN) 到 Transformer 时代，计算机视觉的底层特征提取器（Backbone）经历了从“单纯堆叠深度”到“兼顾感受野与计算量”，再到“追求全局注意力与多尺度融合”的演进。本文档从全局视角总结其核心架构，并对高频面试考点与底层数学逻辑进行深度展开。

---

## 一、 标准 5-Stage 层级设计范式详解

现代视觉 Backbone（如 ResNet, Swin Transformer）几乎都遵循**层级化（Hierarchical）**的 5-Stage 结构。网络在不断向后推进时，严格遵循**“空间分辨率减半，通道维度翻倍”**的法则。

### 1. Stage 拆解（以 224x224 输入为例）

| Stage | 核心操作与网络结构 | 输出分辨率 (下采样率) | 输出通道 | 核心特征层级与检测任务关联 |
| :--- | :--- | :--- | :--- | :--- |
| **Stage 1 (Stem)** | 7x7 大卷积 (Stride=2) + MaxPool (Stride=2) | 56x56 (1/4) | 64 | **浅层底座**：快速降维，节省显存。提取最底层的边缘、轮廓和颜色特征。 |
| **Stage 2 (C2)** | 堆叠基础 Block，无下采样 | 56x56 (1/4) | 256 | **高分辨率细节**：对应 FPN 的 P2，用于检测微小目标。 |
| **Stage 3 (C3)** | 降采样 (Stride=2) + 堆叠 Block | 28x28 (1/8) | 512 | **中级特征**：感受野扩大，捕捉物体局部结构。对应 FPN 的 P3。 |
| **Stage 4 (C4)** | 降采样 (Stride=2) + 大量堆叠 Block | 14x14 (1/16) | 1024 | **核心语义特征**：兼具空间位置信息与高级语义。网络最深的一个 Stage，对应 FPN 的 P4。 |
| **Stage 5 (C5)** | 降采样 (Stride=2) + 堆叠 Block | 7x7 (1/32) | 2048 | **全局抽象**：感受野极大，包含高度浓缩的语义，用于分类或大目标检测 (P5)。 |

### 2. Stage 设计的高频深度追问
*   **为何 Stage 4 (C4) 的 Block 数量压倒性地多？**
    *   1/16 的分辨率是一个“黄金折中点”。如果把计算量堆在 1/4 (C2)，由于特征图过大，会导致 FLOPs（浮点运算量）和显存爆炸；如果堆在 1/32 (C5)，小目标的特征早已丢失。C4 能够在可接受的计算开销下，提取极其丰富的语义特征。
*   **Stem 层为什么执着于 7x7 大卷积？**
    *   早期 224x224 的图像输入直接使用 3x3 卷积提取特征会导致初始特征图体积（$H 	imes W 	imes C$）过大。7x7 卷积配合 stride=2，能够一次性获得较大感受野，结合随后的 MaxPool，两步操作将分辨率降至 1/4，极大卸载了后续 Stage 的计算负担。

## 二、 关键技术路线与核心细节推导

### 1. VGG：模块化设计与感受野等效
**核心贡献**：证明了“网络越深，特征提取能力越强”，并用连续的 $3	imes3$ 小卷积核替代了 AlexNet 中的 $5	imes5$ 或 $7	imes7$ 大卷积核。

**【深度展开】感受野与参数量推导：**
*   **感受野等效**：两层 $3	imes3$ 卷积的感受野 = 一层 $5	imes5$ 卷积。三层 $3	imes3$ = 一层 $7	imes7$。
*   **参数量对比**（假设输入输出通道数均为 $C$）：
    *   1 个 $5	imes5$ 卷积：$5 	imes 5 	imes C 	imes C = 25C^2$
    *   2 个 $3	imes3$ 卷积：$2 	imes (3 	imes 3 	imes C 	imes C) = 18C^2$
*   **结论**：参数量减少了 **28%** ($18/25$)，且多了一次 ReLU 非线性激活，增加了网络的拟合能力。

### 2. ResNet：打破“深度”魔咒的残差连接
**核心贡献**：解决了深层网络由于梯度弥散（Vanishing Gradient）和网络退化（Degradation）导致无法收敛的问题。

**【深度展开】残差如何保证梯度不消失？**
*   **前向传播**：$y = F(x, W) + x$，其中 $F(x)$ 是残差块学习的特征，短接线直接将 $x$ 传到输出。
*   **反向传播**：根据链式法则，$rac{\partial y}{\partial x} = rac{\partial F(x, W)}{\partial x} + 1$。
*   **结论**：无论网络有多深，权重层梯度 $rac{\partial F}{\partial x}$ 衰减得有多小，那个无损的 "+1" 保证了梯度始终非零，能够直接跨层回传，使得成百上千层的网络顺利训练。
*   **Bottleneck 结构**：在 C4、C5 阶段，为了控制高维特征图（如 256 通道）的计算量，ResNet 采用 $1	imes1$（降维） $
ightarrow$ $3	imes3$（提取特征） $
ightarrow$ $1	imes1$（升维） 的瓶颈结构，极大降低了 FLOPs。

### 3. MobileNet：轻量化标杆与空间/通道解耦
**核心贡献**：提出了**深度可分离卷积 (Depthwise Separable Convolution)**，成为所有轻量级网络（甚至是现代 ConvNeXt）的基石。

**【深度展开】计算量 (FLOPs) 锐减的数学推导：**
假设输入特征图为 $D_F 	imes D_F$，输入通道 $M$，输出通道 $N$，卷积核大小 $D_K 	imes D_K$。
*   **标准卷积计算量**：$D_K 	imes D_K 	imes M 	imes N 	imes D_F 	imes D_F$
*   **深度可分离卷积**：
    1.  **Depthwise (DW) 空间过滤**：每个通道独立使用 $D_K 	imes D_K$ 卷积，计算量 = $D_K 	imes D_K 	imes M 	imes D_F 	imes D_F$
    2.  **Pointwise (PW) 通道融合**：使用 $1	imes1$ 卷积融合，计算量 = $1 	imes 1 	imes M 	imes N 	imes D_F 	imes D_F$
*   **压缩比率 (Ratio)**：
    $$ rac{DW + PW}{	ext{Standard}} = rac{D_K^2 M D_F^2 + M N D_F^2}{D_K^2 M N D_F^2} = rac{1}{N} + rac{1}{D_K^2} $$
*   **结论**：如果使用常用的 $3	imes3$ 卷积核，即 $D_K = 3$，且输出通道 $N$ 足够大，压缩比率约等于 $rac{1}{9}$。即计算量和参数量下降了近 **8~9倍**。

### 4. ShuffleNet：抛弃伪轻量，直击 MAC 痛点
**核心贡献**：指出单纯看理论 FLOPs 评价轻量化是不准确的，必须考虑**内存访问代价 (Memory Access Cost, MAC)**，并提出通道重排 (Channel Shuffle)。

**【深度展开】优化 MAC 的四大工程准则：**
1.  **输入输出通道数相同时，MAC 最小**。由均值不等式可推导：假设 FLOPs 为定值 $B = hw c_1 c_2$，则 $MAC = hw(c_1 + c_2) \ge 2hw \sqrt{c_1 c_2} = 2\sqrt{hwB}$，当且仅当 $c_1 = c_2$ 时等号成立。
2.  **过度使用分组卷积 (Group Conv) 会增加 MAC**。虽然 Group 降低了 FLOPs，但要求更多的通道数来保持精度，导致 MAC 飙升。
3.  **网络碎片化（多分支）会降低 GPU 并行度**。Inception 系列分支过多，对硬件并行不友好。
4.  **Element-wise 操作（如 ReLU, Add）的时间开销不容忽视**。尽管它们 FLOPs 为 0，但伴随频繁的显存读写。

### 5. Vision Transformer (ViT) 与 Swin Transformer
**核心贡献**：用纯自注意力机制 (Self-Attention) 替代卷积，获得了全局感受野，统一了 NLP 与 CV 的架构。

**【深度展开】归纳偏置 (Inductive Bias) 与架构演进：**
*   **CNN 的归纳偏置**：拥有“平移不变性”（同一物体在不同位置用同一套权重）和“局部相关性”（相邻像素关联度高）。这使得 CNN 在小数据集上极易收敛。
*   **ViT 的困境**：ViT 几乎没有归纳偏置，模型从零开始学习全局规律，极度依赖海量数据。且原生 ViT 输出单一尺度的特征图，复杂度与像素数呈二次方 $O(N^2)$，无法处理高分辨率图像和直接接入 FPN。
*   **Swin Transformer 的破局 (重回 5-Stage)**：
    *   引入 **Window Attention (窗口注意力)**：将全局计算限制在局部窗口内，计算复杂度从 $O(N^2)$ 降为 $O(N)$。
    *   引入 **Shifted Window (滑动窗口)**：通过偏移窗口解决跨窗口间的信息交流。
    *   **Patch Merging (层级化特征)**：模仿 CNN 的池化，在网络不同层下采样，重新构建了 1/4、1/8、1/16、1/32 的 4 个 Stage，完美契合了目标检测的多尺度需求，让 Transformer 在 CV 各大赛道全面称王。
