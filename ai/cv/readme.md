# 神经网络核心知识详解

## 一、核心基础构件与数值推演

神经网络的预测过程本质上是数据的线性组合与非线性映射。

### 神经元与权重 (Weights, W)、偏置 (Bias, b)

**概念：** 权重决定输入特征的"重要性"，偏置决定神经元激活的"基础门槛"。

**数值示例：** 假设输入特征 x=2.0（比如房间数量）。该特征的权重 W=3.0，偏置 b=1.0。神经元的线性计算结果为：

> z = W · x + b = 3.0 · 2.0 + 1.0 = **7.0**

### 前向传播 (Forward Propagation)

**概念：** 数据从输入层，经过层层线性计算和激活函数，最终得出预测结果的单向流动过程。

**数值示例：** 承接上文的 z=7.0，如果直接输出，这就是一个线性回归。为了处理复杂任务，我们将其通过激活函数（如 ReLU，逢负化零）。因为 7.0 > 0，所以最终预测输出 **y = 7.0**。

---

## 二、流行激活函数 (Activation Functions) 盘点

激活函数用于为网络引入非线性，使其能够拟合复杂的现实世界数据（如图像、语音）。

### ReLU (Rectified Linear Unit)

- **机制：** f(x) = max(0, x)。大于 0 则原样输出，小于 0 则输出 0。
- **优缺点：** 计算极快，解决了正区间的梯度消失问题。目前隐藏层的默认首选。缺点是存在"神经元死亡"问题（负区间梯度永远为 0）。
- **数值示例：** 输入 −3.5，输出 0；输入 2.1，输出 2.1。

### Sigmoid

- **机制：** f(x) = 1 / (1 + e⁻ˣ)。将任何实数压缩到 0 到 1 之间。
- **优缺点：** 适合输出概率或用于二分类任务的最后一层。缺点是容易引发梯度消失（两侧导数趋近于 0），且计算耗时。
- **数值示例：** 输入 0，输出 0.5；输入极大的数（如 100），输出极度逼近 1.0。

### Softmax

- **机制：** 将一组输出转化为概率分布，所有输出之和等于 1。
- **应用：** 多分类任务（如区分猫、狗、猪）的最后一层。
- **数值示例：** 网络输出原始得分 [2.0, 1.0, 0.1]，经过 Softmax 后变为概率 [0.70, 0.26, 0.04]（总和为 1）。

## 三、流行损失函数 (Loss Functions) 盘点

损失函数是衡量模型预测值与真实标签之间差距的标尺。

### MSE (Mean Squared Error, 均方误差)

- **机制：** 预测值与真实值差值的平方和的平均数。
- **应用：** 回归任务（如预测房价、温度）。它对大误差惩罚极重。
- **数值示例：** 真实房价是 5（百万），预测了 3（百万）。损失 L = (5 − 3)² = **4**。

### Cross-Entropy (交叉熵)

- **机制：** 衡量两个概率分布之间的差异。预测概率越接近真实标签，损失越接近 0。
- **应用：** 分类任务。通常与 Softmax 组合使用。
- **数值示例：**
  - 图片是一只猫（真实概率为 1）。模型预测它是猫的概率只有 0.1。交叉熵损失 L = −ln(0.1) ≈ **2.30**（损失很大，说明错得离谱）。
  - 如果预测概率是 0.9，则 L = −ln(0.9) ≈ **0.10**（损失很小）。

### 1. 信息量 (Information Volume)：事件的"惊吓程度"

想象你正在排查识别错误。信息量 $I(x) = -\log(P(x))$ 衡量的就是"这件事发生时，你有多意外"。

- **极高概率事件**：如果模型以 99% 的概率（$P=0.99$）判定这个字是"A"，这毫不意外。代入公式 $-\log(0.99) \approx 0.01$，信息量几乎为 0。
- **极小概率事件**：如果模型认为它是"Z"的概率只有 1%（$P=0.01$），但最终真值标签揭晓它确实是"Z"。代入公式 $-\log(0.01) \approx 4.60$。你会非常震惊（信息量很大），这意味着模型出了严重偏差，需要狠狠修正。

### 2. 熵 (Entropy)：数据的"天然混乱度"

熵是系统所有可能事件信息量的期望（平均值）。它描述的是数据集本身的特性，跟你的模型预测得准不准无关。

- **低熵状态**：一批高清打印体的车牌号，肉眼一眼就能看出是哪个字母，几乎没有歧义。
- **高熵状态**：一批极度潦草的医生处方手写体。同一个符号既像"0"又像"O"还像"D"。这种数据天生带有极高的不确定性。

### 3. 交叉熵 (Cross-Entropy)：错配的"罚单"

现在把真实标签（绝对真理）和模型的预测结果放在一起比对。假设图片里真真切切写着一个大写字母 "O"。在分类任务的 One-Hot 编码下，真实的概率分布 $P$ 是：`[O: 100%, Q: 0%, D: 0%]`。

我们来看看两个不同模型的"交叉熵罚单"有多大区别：

| 模型表现 | 模型给出的预测概率 (Q) | 交叉熵 Loss 计算过程: $-\sum P(x)\log(Q(x))$ | 最终 Loss 结果 |
| :--- | :--- | :--- | :--- |
| **优秀模型** | `[O: 90%, Q: 8%, D: 2%]` | $-(1 \cdot \log(0.9) + 0 \cdot \log(0.08) + 0 \cdot \log(0.02))$ | $\approx \mathbf{0.10}$ (罚得极轻) |
| **瞎猜模型** | `[O: 10%, Q: 80%, D: 10%]` | $-(1 \cdot \log(0.1) + 0 \cdot \log(0.80) + 0 \cdot \log(0.10))$ | $\approx \mathbf{2.30}$ (罚得极重) |

你会发现，因为真实标签里 $Q$ 和 $D$ 的概率是 $0$，它们后面的计算直接被"抹零"了。交叉熵的本质变成了一个极其霸道的逻辑："不管你在其他错误选项上纠结了多少，我只盯着你在正确答案上给的概率。给得越低，对数惩罚就越爆炸。"

### 4. 降维打击：为什么不用 MSE（均方误差）？

如果上面的"瞎猜模型"用 MSE 来算 Loss，结果会是：

$$(1.0 - 0.1)^2 + (0 - 0.8)^2 + (0 - 0.1)^2 = 0.81 + 0.64 + 0.01 = 1.46$$

看出了什么问题吗？MSE 的惩罚是温和且有上限的（最大差值不过是 $1^2 = 1$）。而交叉熵的对数曲线在预测概率趋近于 $0$ 时，惩罚会趋近于无穷大。

对于分类任务（尤其是处理相似字符特征回归时），我们绝不容忍"黑白颠倒"的错误。交叉熵通过 $\log$ 函数的特性，对这种离谱错误施加了极端的惩罚，从而在反向传播时，能产生巨大且直接的梯度，逼迫模型迅速纠正。

## 四、核心数学工具与数值示例

神经网络通过计算梯度来感知误差的来源。

### 微分 / 导数 (Derivative)

- **概念：** 衡量变量间的变化率（敏感度）。
- **数值示例：** 函数 y = x²。在 x=3 时的导数（斜率）是 2x = **6**。意思是，此时如果把 x 微微增加 0.01，y 就会剧烈增加 0.06。

### 偏导数 (Partial Derivative)

- **概念：** 控制变量法。多元函数中，冻结其他变量，只看其中一个变量对结果的影响。
- **数值示例：** 损失函数 L = 2 · W₁ + 5 · W₂。此时 ∂L/∂W₁ = **2**。意思是只改变 W₁ 时，它对 L 的影响权重是 2。

### 链式法则 (Chain Rule)

- **概念：** 复合函数的求导法则，也就是反向传播的数学核心（误差传导齿轮）。
- **公式：** dC/dA = (dC/dB) · (dB/dA)
- **数值示例：** 假设 C = 2 · B，且 B = 3 · A。A 对 C 的影响是多少？

> ∂C/∂A = (∂C/∂B) · (∂B/∂A) = 2 · 3 = **6**

## 五、流行优化器 (Optimizers) 盘点

优化器根据梯度信息，决定参数更新的具体步伐。

### SGD (Stochastic Gradient Descent, 随机梯度下降)

- **机制：** 最基础的优化器。严格按照当前计算出的梯度反方向走一步。
- **优缺点：** 简单直接，但遇到"峡谷"地形容易左右震荡，遇到平缓地形容易卡住（鞍点）。
- **数值示例：** 当前权重 W=1.0，计算出梯度为 −4.0，学习率 η=0.1。更新后 W = 1.0 − 0.1 · (−4.0) = **1.4**。

### Momentum (动量法)

- **机制：** 模拟物理学中的惯性。参数更新不仅看当前梯度，还保留了上一步的速度。
- **优缺点：** 能冲过平缓的鞍点，减少峡谷地形的横向震荡。
- **数值示例：** 当前梯度指向"左"，但历史惯性一直往"前"。最终走的方向是"前"和"左"的向量叠加（90% 历史惯性 + 10% 当前梯度），从而平滑了路线。

### Adam (Adaptive Moment Estimation)

- **机制：** 自带导航的智能跑车。结合了动量（控制方向）和自适应学习率（控制步长）。它会为网络中的每一个参数单独计算适合它的学习率。
- **优缺点：** 目前工业界最常用的默认优化器。收敛速度极快，对学习率初始值的设置不那么敏感。
- **数值示例：** 参数 W₁ 经常收到很大的梯度，Adam 会自动缩小 W₁ 的有效学习率防震荡；参数 W₂ 很少更新梯度，Adam 会自动放大 W₂ 的学习率促使其学习。

## 六、白板推演实战：极简网络完整手算

这是面试中最能体现基本功的环节。设计一个包含 1 个输入、1 个隐藏层节点、1 个输出层节点的回归网络。

### 1. 初始化状态

**任务：** 输入 x=2.0，期望输出真实标签 y_true = 5.0。

**参数：**

| 层级 | 参数 | 值 |
|------|------|-----|
| 隐藏层（使用 ReLU） | w₁ | 0.5 |
| 隐藏层（使用 ReLU） | b₁ | 1.0 |
| 输出层（线性） | w₂ | 2.0 |
| 输出层（线性） | b₂ | 0.0 |

**损失函数：** L = ½(y_pred − y_true)²

### 2. 前向传播（得出预测与误差）

| 步骤 | 计算 | 结果 |
|------|------|------|
| 隐藏层组合 | z₁ = w₁ · x + b₁ = (0.5 · 2.0) + 1.0 | **2.0** |
| 隐藏层激活 (ReLU) | a₁ = max(0, 2.0) | **2.0** |
| 输出层预测 | y_pred = w₂ · a₁ + b₂ = (2.0 · 2.0) + 0.0 | **4.0** |
| 计算 Loss | L = ½(4.0 − 5.0)² | **0.5** |

> 当前预测 4.0，目标是 5.0。

### 3. 反向传播（链式法则算梯度）

从后往前，计算每个参数对 Loss 的偏导数。

**Loss 根源误差：**

> ∂L/∂y_pred = (y_pred − y_true) = 4.0 − 5.0 = **−1.0**

**输出层参数梯度：**

> ∂L/∂w₂ = (∂L/∂y_pred) · a₁ = (−1.0) · 2.0 = **−2.0**
>
> ∂L/∂b₂ = (∂L/∂y_pred) · 1 = **−1.0**

**误差回传隐藏层：**

> ∂L/∂a₁ = (∂L/∂y_pred) · w₂ = (−1.0) · 2.0 = **−2.0**
>
> 因 z₁ = 2.0 > 0，ReLU 导数恒为 1，即 ∂a₁/∂z₁ = **1.0**

**隐藏层参数梯度：**

> ∂L/∂w₁ = (∂L/∂a₁) · (∂a₁/∂z₁) · x = (−2.0) · 1.0 · 2.0 = **−4.0**
>
> ∂L/∂b₁ = (∂L/∂a₁) · (∂a₁/∂z₁) · 1 = (−2.0) · 1.0 · 1.0 = **−2.0**

### 4. 梯度下降（SGD 优化器更新参数）

设学习率 η=0.05。公式：W_new = W_old − η · 梯度。

| 参数 | 计算 | 更新后值 |
|------|------|----------|
| w₁ | 0.5 − 0.05 · (−4.0) | **0.7** |
| b₁ | 1.0 − 0.05 · (−2.0) | **1.1** |
| w₂ | 2.0 − 0.05 · (−2.0) | **2.1** |
| b₂ | 0.0 − 0.05 · (−1.0) | **0.05** |

### 5. 学习效果验算

用更新后的参数再次前向传播：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 新 z₁ | (0.7 · 2.0) + 1.1 | **2.5** |
| 新 a₁ | ReLU(2.5) | **2.5** |
| 新预测值 y_pred_new | (2.1 · 2.5) + 0.05 | **5.3** |

**结论：** 经过一次完整的训练迭代，网络的预测值从 4.0 变成了 5.3。Loss 从 0.5 断崖式下降至 0.045。模型成功"学"到了更接近目标值（5.0）的参数。
