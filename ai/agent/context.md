# 记忆管理
## 记忆什么？ 不能通过工具获取的
- 用户的相关profile
- 反馈记忆： 用户纠正了什么，没纠正什么？ 用户肯定了什么？
- 项目记忆： 时间、地点、状态等，记录为什么
- 引用记忆： 外部依赖，服务器地址等，设计文档地址等
## 不存什么
- 代码模式，架构，文件路径、代码结构，可以直接获取的不要存储
- 版本记录
- 调试和修复方案
- 说明文件里有的
- 临时性的规则
## 记忆检索： active call； 每一轮均注入；记忆过期提醒
- 扫描： 扫描记忆目录，读取上限200个，且只读前面30行
- 摘要： 记忆整理拼接，类型：名字：时间：描述
- 选择： 输入和记忆给另外一个llm模型，返回最相关记忆；选确定的；校验返回的记忆文件，看是否存在
- 注入： 记忆文件注入；每轮最多5条记忆，每个4000字节；不重复注入；
## 记忆文件设计： 关键词，时间，原文等
## 谁来写记忆？
- 后台agent写记忆
- 权限要限制；限制写入目录范围
- 两轮对话策略：读取所有记忆文件和最近对话，并行写入所有记忆文件
- 互斥机制： 主模型自己写了，后台就不继续写了
- 游标和合并： 消息游标，用于控制记忆提取消息范围
