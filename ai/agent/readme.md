## LORA 原理
- 冻结原是权重，加一个低秩旁路，训练只更新这个旁路
- A举证：负责：找到关键方向，d-r
- B矩阵：负责映射回完整空间，r-d
- r维度: 任务适配的内在维度
- 小矩阵为什么可疑注入新能力？
- - 权重举证是一个函数
  - 修正定向：r维度的输出被改变，其他维度不变，保证了不会灾难性遗忘
  - 低秩约束限制了修改范围，让变化只在低维子空间里
  - 初始参数是0
- 为什么小矩阵是dizhi的？
- - 内在维度：只有几百或几十个，其他参赛调整是冗余的，真正的更新是在一个低维子空间里
  - 微调在数学上本来就是低秩的
