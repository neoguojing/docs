# 人脸档案

## 实时聚类

在真实的监控场景中，同一个人的正脸、侧脸、戴口罩、不同光照下的特征差异极大。如果使用单一的均值特征（Centroid）来代表该目标，会导致特征被“中和”或“污染”。

本方案引入**特征子中心 (Sub-center / Multi-prototype)** 概念，将检索与聚类的粒度从“档案级”下沉到“姿态级”，有效解决类内多态性（Intra-class variance）问题。

---

## 一、 核心概念：多中心档案模型 (Multi-Prototype Profile)

传统的“一人一档”模型是 `1 Profile = 1 Feature`。
基于子中心的模型升级为 `1 Profile = [Sub-Center_1, Sub-Center_2, ..., Sub-Center_K]`。

* **表征独立：** 每个子中心代表不同的视觉模式（如子中心A=正脸，子中心B=侧脸，子中心C=戴口罩）。
* **动态伸缩：** 档案内的子中心数量 $K$ 随目标展现出的新姿态动态增加，同时设置上限（如 $K \le 5$）以控制存储规模。

---

## 二、 实时分类任务设计 (Online Classification)

在分类时，检索的粒度下沉到“子中心”级别，匹配和更新机制更加精细。

### 1. 检索与多模态匹配
* **输入：** 实时抓拍特征 $F_{new}$。
* **执行检索：** 在底库中检索相似度最高的 **Top-N 个子中心**。
* **档案归属判定：** 将命中的子中心映射回对应的档案（Profile）。只要某档案的**任意一个**子中心与 $F_{new}$ 极度相似，即判定命中该档案。

### 2. 动态子中心分裂与更新策略（核心逻辑）
设定两个相似度阈值：更新阈值 $T_{update}$（如 0.90）和 归档阈值 $T_{add}$（如 0.80）。

* **情况 A（常规更新）：** 命中某档案，且与该档案中**最近的子中心**相似度 $\ge T_{update}$。
  * *动作：* 说明当前的抓拍和该子中心高度一致（如都是清晰正脸）。利用 EMA（指数滑动平均）仅更新该命中的子中心，不污染该档案的其他子中心。
* **情况 B（分裂新子中心）：** 命中某档案（通过时空关联或中等视觉相似度确认），但与该档案内所有子中心的相似度都介于 $T_{add}$ 和 $T_{update}$ 之间。
  * *动作：* 判定为该目标的一个**新姿态**。系统不强行融合，而是将 $F_{new}$ 作为该档案的**一个新的子中心**独立保存。
* **情况 C（新建档案）：** 与全库所有的子中心相似度都 $< T_{add}$。
  * *动作：* 建立全新档案，$F_{new}$ 成为该新档案的第一个（也是唯一一个）子中心。

---

## 三、 离线聚类任务设计 (Offline Graph Clustering)

引入子中心概念后，离线图聚类升级为**两阶段聚类 (Two-Stage Clustering)**。既能提升聚类纯度，又能将图计算的节点规模缩小几个数量级。

### 阶段 1：微聚类提取临时子中心 (Micro-Clustering -> Sub-centers)
* **目标：** 将海量冗余的原始抓拍（如某人在镜头前站了 10 秒产生的 300 张高度重合废片）压缩为少量极高质量的子中心。
* **操作：** 
  * 按时间窗口或轨迹 (Tracklet) 为单位，对孤立抓拍进行局部聚类（使用 Leader Clustering 或 K-Means）。
  * 将高度密集的簇提取为一个均值向量，作为“临时子中心”。
* **效果：** 可将千万级原始抓拍图，浓缩为十万级别的特征子中心节点。

### 阶段 2：基于子中心的全局宏聚类 (Macro-Clustering with GCN & DBSCAN)
此时的图结构（Graph），**节点不再是原始抓拍图，而是第一阶段提取的子中心集合**。

1. **构图 (Graph Construction)：**
   * 计算子中心之间的余弦距离构建 K-NN 图。
   * **时空边权重：** 若两个子中心属于同一条轨迹，强制连接一条高权重边。
2. **GCN 节点特征平滑：**
   * 将图输入 GCN。GCN 会让同一条轨迹上的“侧脸子中心”吸收“正脸子中心”的信息，解决姿态跨度过大带来的特征断层问题。
3. **DBSCAN 连通划分：**
   * 在 GCN 平滑后的图上运行 DBSCAN 聚类。
   * 此时聚出来的每一个簇（Cluster），即代表物理世界中的一个**完整的身份档案（Profile）**。
4. **结果映射与档案重组：**
   * 簇内包含的所有子中心，统一归属于该新建/合并后的档案。
   * 无法与任何核心子中心连通的散落节点，被标记为噪声并降级存储。

---

## 四、 方案优势总结

1. **特征纯度极高：** 彻底避免了“正脸+侧脸=畸形均值脸”的特征污染灾难，分类召回率与准确率大幅提升。
2. **图计算降维打击：** 离线 GCN 和 DBSCAN 的时间复杂度从 $O(N^2)$ 降低到了 $O(M^2)$（$M$ 为子中心数量，$M \ll N$），使得大规模图聚类在工程上具有现实可行性。
3. **时空语义更清晰：** 一个子中心往往天然对应着一段连续的时空轨迹 (Tracklet)，更易于与业务规则（时空冲突/伴随分析）进行结合。

本方案旨在通过实时特征检索与离线图聚类双引擎架构，实现海量人脸、人体抓拍数据的精确归档，并附带核心聚类算法（GCN、DBSCAN）的推演、底层代码实现以及端到端的算法工作流。

## 一、 系统整体数据流规划

| 任务类型 | 触发时机 | 核心算法与组件 | 目标与作用 |
| :--- | :--- | :--- | :--- |
| **分类任务** | 实时（视频流/抓拍接入） | 质量过滤、cstk / Milvus 向量检索、特征平滑更新 | 毫秒级归档，判定抓拍所属身份或新建档案。 |

## 二、 全流程算法执行描述 (End-to-End Algorithm Flow)

为了将实时分类与离线聚类串联，以下是系统端到端处理一条抓拍数据并进行全局优化的标准算法流程。

### 阶段 1：实时分类与建档 (Online Classification)
**输入：** 实时抓拍帧 $I_t$，元数据 $M_t = (Time, Location, CameraID)$
**输出：** 档案更新记录，或进入待聚类队列。

1. **特征提取与质量评估：**
   - 提取人脸特征 $F_{face}$，人体特征 $F_{body}$，并计算图像质量分 $Q$。
   - **IF** $Q < Q_{threshold}$（低质量废片）：直接丢入离线 Pending 队列，不参与实时检索。
2. **特征检索 (Top-K)：**
   - 在底库中执行 $cstk.search(F_{face}, K=50)$，获取候选档案列表 $C = \{C_1, C_2, ..., C_K\}$ 及余弦相似度 $S = \{s_1, s_2, ..., s_K\}$。
3. **时空冲突过滤：**
   - 遍历 $C$，比对 $M_t$ 与候选档案的最后活跃时空。若违背物理移动速度（如1分钟跨越50公里），则从候选列表中剔除该档案。
4. **分类判定与更新：**
   - 取过滤后相似度最高的档案 $C_{max}$ 及其得分 $s_{max}$。
   - **IF** $s_{max} > T_{high}$ (强命中)：将 $I_t$ 归入档案 $C_{max}$。使用 EMA 更新该档案底库特征：$F_{base} = \alpha F_{face} + (1-\alpha) F_{base}$。
   - **ELSE IF** $T_{low} \le s_{max} \le T_{high}$ (存疑)：将 $I_t$ 写入 Pending 队列，待离线聚类判定。
   - **ELSE** (新建)：为 $I_t$ 建立新档案 $Profile_{new}$，特征入库。

### 阶段 2：离线图聚类纠错 (Offline Graph Clustering)
**输入：** 过去 24 小时的 Pending 队列特征 $X_{pending}$，以及发生过更新的档案基准特征 $X_{base}$。组合为全集 $X$。
**输出：** 档案的合并、拆分或新档案确立。

1. **构建初始 K-NN 图：**
   - 计算 $X$ 中所有特征的两两余弦相似度，相似度 $> T_{edge}$ 的节点连边，生成初始邻接矩阵 $A$。
2. **时空先验图修剪 (Graph Pruning)：**
   - 检查 $A$ 中的边 $(u, v)$。若节点 $u, v$ 在时空上存在硬冲突，强制令 $A_{u,v} = 0$。
   - 若 $u, v$ 在同一摄像头连续时间段出现，增加权重 $A_{u,v} = A_{u,v} \times 1.2$。
3. **GCN 特征平滑 (Feature Smoothing)：**
   - 构造自环矩阵 $\tilde{A} = A + I$。
   - 计算度矩阵归一化：$\hat{A} = \tilde{D}^{-\frac{1}{2}} \tilde{A} \tilde{D}^{-\frac{1}{2}}$。
   - 执行图卷积，得到纠偏后的特征：$X_{enhanced} = L2\_Normalize( \text{ReLU}(\hat{A} X W) )$。
4. **DBSCAN 连通分量提取：**
   - 将 $X_{enhanced}$ 输入 DBSCAN，利用参数 $Eps$ 和 $MinPts$ 扫描核心点并扩展边界。
   - 输出聚类标签集合 $Labels = \{l_1, l_2, ...\}$。
5. **档案结构重组 (Reorganization)：**
   - 若同一个聚类标签 $l_i$ 包含多个现有档案的 $X_{base}$：执行**档案合并 (Merge)**。
   - 若同一个现有档案的多个抓拍特征被分到了不同的聚类标签：执行**档案拆分 (Split)**。
   - 剩余未成簇的孤立点（Noise），标记为“无效抓拍”废弃。

## 三、 实时流：特征检索与档案更新细则

实时流解决单张抓拍的即时归属问题。

1. **质量过滤：** 低质量（模糊、过曝）图像不提取人脸特征，仅保留人体特征与元数据。
2. **特征检索：** 输入高维特征向量，使用近似最近邻 (ANN) 召回 Top-K 档案。
3. **档案特征更新：**
    * **队列维护法 (FIFO)：** 档案维护近 N 次高质量特征列表，检索时计算平均/最大距离。
    * **指数滑动平均 (EMA)：** F_base = a * F_new + (1 - a) * F_base。极省内存，缓慢更新。
    * **质量加权融合：** 根据图像质量分数动态分配权重，计算特征质心。

## 四、 离线流：核心算法推演与代码实现

### 4.1 GCN 图卷积网络：特征平滑与纠偏

GCN 的核心作用是让质量差（模糊）的特征吸收时空相连的高质量特征，在向量空间中“向正确的人靠拢”。其前向传播核心逻辑为：
Output = ReLU( D^(-1/2) * A_tilde * D^(-1/2) * X * W )

#### 数值推演演示
假设有 3 张抓拍图（节点 0, 1, 2）。节点 0 为正脸 X_0 = [10, 0]；节点 1 为模糊侧脸 X_1 = [0, 10]；节点 2 为清晰图 X_2 = [10, 10]。拓扑连通关系为 `0 --- 1 --- 2`。

1. **带自环的邻接矩阵 A_tilde (强制保留自身特征):**
   ```text
   A_tilde = 
   [1, 1, 0]
   [1, 1, 1]
   [0, 1, 1]
   ```

2. **度矩阵的负平方根 D^(-1/2):**
   节点 0 度为 2，节点 1 度为 3。1/sqrt(2) ≈ 0.707，1/sqrt(3) ≈ 0.577。

3. **对称归一化 A_hat = D^(-1/2) * A_tilde * D^(-1/2):**
   ```text
   A_hat = 
   [0.500, 0.408, 0    ]
   [0.408, 0.333, 0.408]
   [0    , 0.408, 0.500]
   ```

4. **特征聚合 A_hat * X:**
   ```text
   [0.500, 0.408, 0    ]   [10,  0]   [5.00, 4.08]
   [0.408, 0.333, 0.408] * [ 0, 10] = [8.16, 7.41]
   [0    , 0.408, 0.500]   [10, 10]   [5.00, 9.08]
   ```
   **结论：** 模糊的节点 1 原本特征为 `[0, 10]`，经过一次图聚合后变为 `[8.16, 7.41]`，成功吸收了节点 0 和 2 的第一维特征，向真实身份靠拢。

#### GCN PyTorch 核心实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def normalize_adjacency_matrix(adj: torch.Tensor) -> torch.Tensor:
    """计算对称归一化邻接矩阵"""
    num_nodes = adj.size(0)
    adj_tilde = adj + torch.eye(num_nodes, device=adj.device, dtype=adj.dtype)
    
    deg = torch.sum(adj_tilde, dim=1)
    deg_inv_sqrt = torch.pow(deg, -0.5)
    deg_inv_sqrt[torch.isinf(deg_inv_sqrt)] = 0.0 # 防除零
    
    deg_mat_inv_sqrt = torch.diag(deg_inv_sqrt)
    return torch.mm(torch.mm(deg_mat_inv_sqrt, adj_tilde), deg_mat_inv_sqrt)

class GCNConv(nn.Module):
    """单层图卷积层"""
    def __init__(self, in_features: int, out_features: int):
        super(GCNConv, self).__init__()
        self.weight = nn.Parameter(torch.FloatTensor(in_features, out_features))
        nn.init.xavier_uniform_(self.weight)

    def forward(self, x: torch.Tensor, norm_adj: torch.Tensor) -> torch.Tensor:
        support = torch.mm(x, self.weight) 
        out = torch.mm(norm_adj, support)  
        return out

class GCN(nn.Module):
    """用于聚类特征增强的双层 GCN"""
    def __init__(self, in_dim: int, hidden_dim: int, out_dim: int):
        super(GCN, self).__init__()
        self.gc1 = GCNConv(in_features=in_dim, out_features=hidden_dim)
        self.gc2 = GCNConv(in_features=hidden_dim, out_features=out_dim)

    def forward(self, x: torch.Tensor, norm_adj: torch.Tensor) -> torch.Tensor:
        x = F.relu(self.gc1(x, norm_adj))
        x = self.gc2(x, norm_adj)
        return F.normalize(x, p=2, dim=1) 
```

### 4.2 DBSCAN 基于密度的聚类

将 GCN 增强后的特征输入 DBSCAN，划分为具体的“人”。
* **核心参数：** Eps（相似度阈值），MinPts（成簇最小点数）。
* **点类型：** 核心点（邻域内点数 ≥ MinPts）、边界点（点数不足，但落在核心点邻域内）、噪声点（孤立废片）。

#### DBSCAN 数值演示
设定 Eps = 1.1，MinPts = 3。平面上有以下点：

| 节点 | 坐标 (X, Y) | 邻域内点集合 (距离 ≤ 1.1) | 数量 | 判定类型 |
|---|---|---|---|---|
| P1 | (1, 1) | P1, P2, P3 | 3 | **核心点** |
| P2 | (1, 2) | P2, P1, P4 | 3 | **核心点** |
| P3 | (2, 1) | P3, P1, P4, P5 | 4 | **核心点** |
| P4 | (2, 2) | P4, P2, P3 | 3 | **核心点** |
| P5 | (3, 1) | P5, P3 | 2 | **边界点** |
| P6 | (8, 8) | P6 | 1 | **噪声点 (-1)** |

**成簇过程：** 算法从 P1 开始创建“簇 1”，并向外感染其邻居 P2, P3。P2, P3 作为核心点继续向外感染 P4, P5。到达 P5 时，因其是边界点，感染停止。最终 {P1, P2, P3, P4, P5} 合并为一个身份档案，孤立点 P6 被丢弃。

## 五、 跨模态与时空约束（Graph 构建前提）

图的质量决定了 GCN 和 DBSCAN 的上限，构建 K-NN 图时必须叠加物理世界约束。

1. **时空冲突阻断 (Hard Constraint):** 若抓拍 A 和 B 视觉相似度极高，但时间差 1 分钟，空间距离相差 50 公里，则**直接切断图边缘**，禁止聚类。
2. **时空邻接增益 (Soft Constraint):** Edge_Weight = Cosine(F1, F2) * (1 + a * 时空重合概率)。时空轨迹重合度越高，边权重越大。
3. **人体特征降维融合：** 遇到背影无脸数据，通过关联的 BBox 以人脸连通分量为锚点拉入档案；无法关联的人体，执行人体特征子图聚类，并使用 `0.7 * FaceScore + 0.3 * BodyScore` 机制进行多模态判定。
