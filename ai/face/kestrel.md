# Kestrel 软件架构设计与全景解析

## 1. 架构概述

**Kestrel** 是一套面向 AI 模型推理与部署的企业级、高性能端到端 SDK 框架。其核心设计采用了**微内核架构（Microkernel Architecture）**与**有向无环图（DAG）流式计算模型**。
核心设计理念是：**“引擎与算法解耦，流程由配置驱动，硬件被高度抽象”**。

## 2. 核心调用链路 (Invocation Chain)

在实际业务线（如身份证识别、视频结构化）的调用过程中，数据流转遵循自上而下的分层架构：
**IPS 业务服务** ➔ **Go SDK Wrapper (KestrelGo/KestrelV1)** ➔ **Kestrel C++ API (`libkestrel_ocr.so`)** ➔ **核心调度框架 (`libkestrel_core.so`)** ➔ **KEP 算法插件** ➔ **底层硬件推理加速 (NART/PPL)**

---

## 3. 逻辑分层架构

| 层级名称 | 核心定位 | 主要组件与模块 |
| :--- | :--- | :--- |
| **1. 业务接入层** | 提供多语言接入，封装底层复杂性 | `Go SDK Wrapper`, `kcommon`, `kutil`, `IPS` 业务服务 |
| **2. 编排与调度层** | 资源池化、拓扑调度、通信协议解析 | **Model Zoo**(资源池), **Pipeline**(流水线), `keson`(通信协议) |
| **3. 核心框架层** | 提供通用基础底座，安全与鉴权 | `libkestrel.so`(抽象框架), `libkestrel_core.so`(微内核), `libkestrel_quotas.so`(鉴权) |
| **4. 领域与插件层** | 业务高级封装与算法动态加载 | 领域模块: `libkestrel_ocr.so`, `face.so` <br>算法插件(.kep): `Textdetection`, `Raven` 等 |
| **5. 硬件与引擎层** | 屏蔽底层硬件差异，提供极致性能 | 视频帧解码、设备抽象、推理引擎(PPL3/NART)、FMA指令集 |
