# FacePed (人脸人体) Pipeline 面试梳理

为了方便面试表达，这里将 FacePed（人脸人体）Pipeline 重新梳理为**四个逻辑阶段**：**检测获取、轨迹关联、质量评估、属性与过滤**。这种结构符合工业界标准的视觉算法链路，能向面试官展现你对系统架构的宏观理解。

## 核心算法链路

| 阶段 | 模块名称 | 输入/核心逻辑 | 输出/目的 | 面试表达要点 (Why) |
| :--- | :--- | :--- | :--- | :--- |
| **1. 基础检测** | **人脸人体检测** | 原始视频帧/图像。 | 输出人脸、人体的 BBox (Bounding Box)。 | 这是整个 pipeline 的基石。通常使用轻量级检测器以保证实时性。 |
| **2. 轨迹与关联** | **轨迹跟踪与选帧** | 检测框序列。 | 目标 Track ID，以及从轨迹中提取的**最优帧/关键帧**。 | 选帧策略能极大降低下游模块的计算量，只需对高质量帧进行后续处理。 |
| | **Cupid 关联匹配** | 人脸和人体的图片及 ROI。 | **匹配 ID 和置信度分数**。 | 解决“这张脸属于哪个身体”的问题（Face-Body Association），多用于跨镜追踪或复杂场景。 |
| **3. 精细化与质量** | **人脸关键点检测** | 选帧后的人脸 ROI。 | 人脸五官关键点坐标 (Landmarks)。 | 为姿态估计和人脸对齐（Alignment）提供前置数据。 |
| | **人脸姿态估计** | 关键点坐标。 | 偏航角、俯仰角、翻滚角 (Yaw, Pitch, Roll)。 | 过滤大侧脸或低头/抬头等极端姿态，保证识别率。 |
| | **人脸模糊度检测** | 人脸 ROI。 | 模糊度得分 (Blur Score)。 | 剔除运动模糊或失焦的人脸。 |
| | **人体质量评估** | 人体 ROI。 | 人体完整度、遮挡程度、分辨率得分。 | 剔除被严重遮挡或残缺的人体。 |
| **4. 属性与过滤** | **人体分类检测** | 质量合格的人体 ROI。 | 衣服颜色、性别、长短袖等结构化属性。 | 用于下游的业务检索或画像分析。 |
| | **人体/人脸过滤** | 综合前面的质量分、姿态、模糊度。 | **最终的高质量结构化数据**。 | 拦截低质数据，防止脏数据污染底库或影响业务准确率。 |

## 面试话术建议 (如何串联讲解)

> “我们的 FacePed Pipeline 主要分为四个阶段。
>
> **首先是前端的检测与跟踪：** 视频流进来后，先经过人脸人体检测器抓取目标，接着通过多目标跟踪（MOT）生成轨迹。为了节省算力，我们会在这里做**选帧**，提取最具代表性的帧进入下游。同时，使用 **Cupid 模块**将分离的人脸和人体 ROI 进行关联，输出匹配 ID，确保人脸和人体属于同一个 Target。
>
> **其次是质量把控：** 选出的高价值帧会并行进入质量评估网络。人脸分支会计算关键点、姿态角和模糊度；人体分支则评估完整度和遮挡情况。
>
> **最后是属性提取与清洗：** 基于前面的质量评估结果进行**过滤**，剔除侧脸、模糊、严重遮挡的废片。只有满足阈值的高质量目标，才会送入人体分类网络提取属性（如衣着颜色等），最终输出高质量的结构化数据供业务端使用。”
