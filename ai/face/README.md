    • 园区安防：围绕人员、车辆等目标进行识别、告警、布控和轨迹分析。
    • 人员能力：人脸、人像/人体分析、人脸人体聚类，形成从“单次抓拍”到“人员档案”的能力。
    • 算法工程化：支持检测、分类、实例分割、语义分割等视觉算法类型。
    • 训练推理一体：训练侧产生模型后，由推理平台负责模型进入运行环境、算法启动、部署和持续推理。
    • 数据闭环：算法输出不仅是一个类别或框，还包括抓拍图片、结构化数据、特征，并进入后续聚类/大数据分析。
